# LBL IT Lessons

Отдельный сайт с материалами уроков курса LBL IT Department (Fullstack + AI для будущих врачей и биомедицинских инженеров). Сайт курса: https://samandar90.github.io/lbl-it-department/.

У каждого урока две страницы:

- **Конспект** (`#/<id>`) — объяснение темы, практика по шагам с кодом, встроенный редактор с живым результатом, вопросы для самопроверки и домашнее задание. Студенты открывают его во время урока и после.
- **Слайды** (`#/<id>/slides/<номер>`) — презентация для проектора. ← → или пульт листают, F включает полный экран, N показывает заметки преподавателя. На слайдах с кодом справа работает готовое приложение.

Всё на русском и узбекском; язык общий с сайтом курса (`?lang=uz` или переключатель RU/UZ).

## Уроки

| id      | Урок                                                                             | Практика                                            |
| ------- | -------------------------------------------------------------------------------- | --------------------------------------------------- |
| `trial` | Пробный урок, 9 ноября, 16:00, кабинет 718: «Твоё первое медицинское приложение» | Калькулятор ИМТ на HTML, CSS и JavaScript за 4 шага |

## Разработка

Node.js 22.18+ или 24+. Стек: React, TypeScript, Vite, CSS, Lucide.

```sh
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

Готовый статический сайт — в `dist/`. Маршруты на `#`, поэтому сборка работает на GitHub Pages по любому пути.

## Как добавить урок

1. Создай `src/lessons/<id>.ts` по образцу `trial.ts`: слайды (`slides`) и блоки конспекта (`blocks`), каждый текст в виде `{ ru, uz }`.
2. Если в уроке есть практика с кодом, опиши шаги в отдельном модуле, как `src/lessons/bmi.ts`, и подключи его в поле `project`.
3. Добавь урок в `src/lessons/index.ts`.
4. `npm test` проверит, что слайды и конспект заполнены и у каждого текста есть узбекский перевод.

## Структура

- `src/lessons/` — данные уроков и код практических заданий.
- `src/pages/` — главная, конспект и слайды.
- `src/components/` — шапка, контакты, блок кода и редактор.
- `src/copy.ts` — общие тексты интерфейса и контакты.
- `tests/` — проверка калькулятора ИМТ и полноты уроков.

Код студентов выполняется в изолированном `iframe` (`sandbox="allow-scripts"`) и никуда не отправляется.
