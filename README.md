# LBL IT Lessons

Отдельный сайт с материалами уроков курса LBL IT Department (Fullstack + AI для будущих врачей и биомедицинских инженеров). Сайт курса: https://samandar90.github.io/lbl-it-department/.

У каждого урока две страницы:

- **Конспект** (`#/<id>`) — объяснение темы, практика по шагам с кодом, встроенный редактор с живым результатом, вопросы для самопроверки и домашнее задание. Студенты открывают его во время урока и после.
- **Слайды** (`#/<id>/slides/<номер>`) — презентация для проектора. ← → или пульт листают, F включает полный экран, N показывает заметки преподавателя. На слайдах с кодом справа работает готовое приложение.

Всё на русском и узбекском; язык общий с сайтом курса (`?lang=uz` или переключатель RU/UZ).

## Уроки

Программа года — 144 урока, по три в неделю (`src/plan/plan.ts`), показана на главной странице.

- **Месяц 1 готов полностью (12 уроков):** вводный урок без кода, клавиатура и мышь, файлы и папки, браузер, установка программ, VS Code, HTML, структура страницы, ссылки и картинки, CSS, карточка-визитка и публикация на GitHub Pages. Рассчитан на студентов, которые почти не работали с компьютером.
- **Месяц 2** — то, что раньше было в первом месяце: формы, Git, Flexbox и Grid, мобильная версия.
- **Месяцы 3–12** — программа курса: `src/plan/laterMonths.ts` сгенерирован из `src/curriculum.ts` сайта курса (одна тема недели — один урок).
- Практикум «Калькулятор ИМТ» (`#/bmi`) стоит в 3-м месяце, на уроке про обработчики событий.

Метод менторства: [MENTORING.md](MENTORING.md). Короткая версия для студентов — раздел «Как мы учимся» на главной.

## Разработка

Node.js 22.18+ или 24+. Стек: React, TypeScript, Vite, CSS, Lucide.

```sh
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

Готовый статический сайт — в `dist/`. Маршруты на `#`, поэтому сборка работает на GitHub Pages по любому пути.

## Как добавить урок

1. Обычный урок описывается через `standardLesson` из `src/lessons/build.ts` — по образцу `src/lessons/month1Web.ts`. Шаблон сам строит слайды и конспект в одном ритме: обход, цели, главное, пример, практика, частые ошибки, самопроверка, домашнее задание. Особые уроки, как `firstLesson.ts`, можно описать вручную: слайды (`slides`) и блоки конспекта (`blocks`), каждый текст в виде `{ ru, uz }`.
2. Код практики опиши в отдельном модуле, как `src/lessons/doctorCard.ts` или `src/lessons/bmi.ts`, и подключи его в поле `project`. Дату, время и место урока (поле `schedule`) указывай, когда они известны.
3. Добавь урок в `src/lessons/index.ts` и замени название на его `id` в `src/plan/plan.ts`.
4. `npm test` проверит, что слайды и конспект заполнены и у каждого текста есть узбекский перевод.

## Структура

- `src/lessons/` — данные уроков и код практических заданий.
- `src/pages/` — главная, конспект и слайды.
- `src/components/` — шапка, контакты, блок кода и редактор.
- `src/copy.ts` — общие тексты интерфейса и контакты.
- `tests/` — проверка калькулятора ИМТ и полноты уроков.

Код студентов выполняется в изолированном `iframe` (`sandbox="allow-scripts"`) и никуда не отправляется.
